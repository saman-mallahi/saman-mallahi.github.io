# Saman Mallahi — GitHub Pages Resume

A clean, responsive personal resume website generated from the 2026 CV.

## Deploy

1. Upload the contents of this folder to the root of your GitHub repository.
2. Push to the `main` branch.
3. GitHub Actions will deploy the site automatically.
4. In **Settings → Pages**, select **GitHub Actions** as the source if GitHub asks you to configure Pages.

The CV PDF is included and linked from the website.
